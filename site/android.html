Pi-Bolt for Android · 0.6.0

Pi-Bolt,
in your pocket.

The Pi coding agent runs on the phone itself: projects with their files, bash, git, ripgrep and fd, your own model provider keys, sessions you can resume and fork. No computer, no Termux. And when you are at your desk, the same app remote-controls Pi-Bolt on your computer, paired by QR code and end to end encrypted.

Install

Four steps.
A few minutes.

  1. 01

    Download

    Tap Download the APK on your phone. Android may warn that the file can harm your device: it is an app from outside the Play Store, so tap Download anyway.

  2. 02

    Install

    Open the file. The first time, Android asks to allow installs from your browser: allow it, go back, and tap Install.

  3. 03

    Add a model key

    The first start asks for a key from a model provider (Anthropic, OpenAI, OpenRouter and others). It stays on the phone, in Pi's own auth.json.

  4. 04

    Start a project

    Make a new project or clone one from git, and ask Pi. To drive your computer's Pi-Bolt instead, run pi-bolt remote-control enable there once, then /remote-control, and scan its QR code from the app.

Needs

Android 8.0 or later on a 64-bit ARM phone, about 400 MB free, and a key from a model provider. Remote control also needs a Pi-Bolt with the /remote-control command on the computer, turned on with pi-bolt remote-control enable.
