Pi-Bolt
Benchmarks Extensions Docs GitHub

The Pi coding agent, compiled to machine code.

Pi-Bolt is Pi as one native executable for Linux and macOS. Every function is compiled before you run it, so nothing is parsed or JIT-compiled at launch: it starts two to three times sooner than Pi on Bun and uses about a third of its CPU.

curl -fsSL https://pi-bolt.opensec.in/install.sh | sh

Or npm install -g pi-bolt. Then run pi-bolt in your project.

Launch to prompt

Pi-Bolt45 ms
Pi on Bun 1.4.2128 ms
Pi on Node 22303 ms

Pi-Bolt against Pi 1.0.0 on Bun and Node, from launch to an interactive prompt, measured on an AMD EPYC 7B13 server and replayed ten times slower. On your machine the times differ; the order does not.

The Pi you already use, without the wait

Your providers, settings, sessions and extensions carry over from ~/.pi/agent. Pi-Bolt changes how Pi runs, not what it does.

Compiled ahead of time

Every function is turned into x86-64 or ARM64 machine code when the executable is built, and Pi's modules are stored already loaded. Launching maps them from the file.

Less CPU over a session

Long answers are drawn incrementally and large files are written without freezing the screen, so a session costs about a third of the CPU of Pi on Bun.

Self-contained

One executable, no Node.js or Bun required. Releases are signed, the installer checks them, and extensions install with Pi-Bolt's own package manager when npm is absent.

Benchmarks

Pi run three ways: compiled by Pi-Bolt (0.7.0 measures the same as the 0.6.1 shown), and Pi 1.0.0 as released on stock Bun and from its npm package on Node. Medians of fresh processes, interleaved across the runtimes. Lower is better.

These are measurements, not guarantees. Each set comes from one machine: an AMD EPYC 7B13 server for Linux, an M5 MacBook Air for macOS. On other hardware the times differ; what carries over is the comparison. Every figure, the method and the raw data are in BENCHMARKS.md.

Extensions

Pi extensions and Pi packages work as they do in Pi. The installer offers two that OpenSec maintains for Pi-Bolt, prebuilt for Bun so that they load without being transpiled.

opensec-pi-subagents

Specialized agents in separate sessions that inherit the parent's model and thinking level, with parallel workflows and scheduled jobs.

pi-bolt install npm:opensec-pi-subagents

opensec-pi-todo

A todo list for the model, shown as a live panel above the editor. It survives /reload and conversation compaction.

pi-bolt install npm:opensec-pi-todo
