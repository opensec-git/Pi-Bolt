Pi-Bolt documentation

Pi-Bolt is the Pi coding agent compiled ahead of time to native code. It is the Pi you already use, with the same commands, sessions, settings, providers and extensions, as one executable. Against Pi as released on Node 24, it writes a large file through a tool call about 120 times faster, uses 8 times less CPU while a long answer streams, 7 times less over a session, and under a quarter of the memory.

Install Pi-BoltOne command on Linux, macOS, Windows and Android, or npm. QuickstartRun your first session, and use Pi-Bolt next to Pi. Choose a buildThe default build, or the JIT build for heavy extensions. ExtensionsRun Pi extensions as they are, or compile them in. BenchmarksTime, CPU and memory against Pi on Bun and Node. TroubleshootingCheck the compiled code, fix common problems, report a bug.

What Pi-Bolt is#

Pi is a TypeScript program. Stock Pi runs on Bun or Node, which parse its code at every launch and compile the hot parts with a just-in-time (JIT) compiler while it runs. Pi-Bolt compiles every function of Pi to machine code when the executable is built, and stores Pi's modules already loaded. At launch there is nothing to parse and nothing to warm up.

What stays the same:

  • Your configuration. Pi-Bolt reads ~/.pi/agent: your providers and logins, settings, sessions, skills, prompt templates and extensions.
  • Pi's behavior. Pi-Bolt is Pi's own source with a small set of fixes on top, not a rewrite. Each release is built on a named Pi release, and pi-bolt --version shows which.
  • Your Pi installation. Pi-Bolt installs next to Pi as pi-bolt. Both can stay installed.

What changes is how Pi runs: it starts sooner, uses less CPU and memory over a session, and handles long answers and large file writes far more cheaply. See How it works and Benchmarks.

Supported platforms#

PlatformRequirements
Linuxx86-64 or ARM64 with glibc 2.17 or later (Ubuntu 20.04+, Debian 11+, RHEL/Rocky 8+, Amazon Linux 2, Raspberry Pi OS 64-bit). musl is not supported.
macOSmacOS 13 or later on Apple silicon
WindowsWindows 10 (1809) or later, or Windows 11, on x64. Windows on ARM64 runs the x64 build in Windows 11's x64 emulation.
AndroidAndroid 7 or later on 64-bit ARM, in Termux (see Android)

There is no build for Intel Macs.
