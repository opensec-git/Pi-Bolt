Pi-Bolt 1.1.7 is [1.1.6](1.1.6.md) with more mobile UI kit components, package pages, Home tiles and an RPC command
that lists providers. Pi is still 1.5.0. The engine is unchanged, so the runtimes are 1.1.6's.

### Added

- **More of the mobile UI kit** ([#304](https://github.com/opensec-git/Pi-Bolt/pull/304)):
  - **Components:**
    - `chart`: line, bar, area and sparkline charts;
    - `table`: typed, sortable and filterable columns, with row taps;
    - `location`: opens the phone's maps app.

    The terminal shows each of them as text.
  - **Package pages and Home tiles:** packages register them with `pi.registerPage()` and `pi.registerTile()`.
    - RPC and remote-control clients list and open pages with `get_pages`, `open_page` and `close_page`.
    - The Pi-Bolt app opens a package's pages from Settings, without a session, and shows its tile on Home when the
      user turns it on.
    - Tiles have their own slot, size limits and at most one update a second. `pi-bolt mobile-ui check --tile` checks
      them.
  - See [Package pages and Home tiles](../../packages/coding-agent/docs/mobile-ui.md#package-pages-and-home-tiles).
- **RPC `get_providers`** ([#306](https://github.com/opensec-git/Pi-Bolt/pull/306)): lists every provider (built-in,
  registered by an extension, or in `models.json`). For each one it gives:
  - its name and origin;
  - whether its auth works now, and the kind of stored credential;
  - whether it takes an API key (with the `$NAME` variables an extension declares) or has a login flow;
  - its chat models, and which of them can be used now.

  Credentials are checked again first, so a key stored after startup shows up. Credential values are never included.
  See [get_providers](../../packages/coding-agent/docs/rpc-commands.md#get_providers).

### Changed

- **A reliable RPC memory floor in the soak benchmark** ([#310](https://github.com/opensec-git/Pi-Bolt/pull/310)):
  - `bench/stress.py` now samples memory after every prompt and reports floors to 0.1 MB.
  - `--soak-runs N` repeats the soak and reports the median floor.
- **The 1.1.6 "+2 MB RPC floor" was noise.** The old floor was the lowest of 5 samples, rounded to whole MB.
  - **Repeated runs:** over 15 runs of each build, 1.1.6 is +0.5 ± 0.5 MB above 1.1.5.
  - **Heap snapshots:** 1.1.6 holds 0.1 MB more live JS heap, the size of the UI kit's code. That doesn't grow with
    prompts.

Also since 1.1.6, outside the release archives:

- **Android app 0.7.0:** native UIs for Pi packages, and engine 1.1.6.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
