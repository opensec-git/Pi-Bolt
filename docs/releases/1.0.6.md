Pi-Bolt 1.0.6 is a performance release: macOS starts about 10% cheaper again, Windows starts faster and the Windows -jit
build uses less memory, long sessions open faster, and Pi uses about half the CPU while it sits idle on a Mac. Pi behaves as
in 1.0.5. Everything else is [1.0.5](1.0.5.md).

### Fixed

- **macOS releases start without the libSystem shim** ([#192](https://github.com/opensec-git/Pi-Bolt/pull/192)): since
  1.0.3 the macOS archives were built without `libsystem/` beside `pi-bin` (#139), because the build read the linked libraries
  in a form that Xcode 16 no longer prints. Starting took about 16 M more instructions than it should. The archives have it
  again, and a release now stops if a macOS archive lacks it.

### Changed

- **Windows starts faster** ([#186](https://github.com/opensec-git/Pi-Bolt/pull/186)): the Windows build splits its code,
  as the macOS and Linux builds have since 1.0.3, and the order Pi's code and heap are laid out in was recorded again for it.
- **Windows -jit build** ([#187](https://github.com/opensec-git/Pi-Bolt/pull/187)): it reserves 128 MB for code the JIT
  writes instead of 1 GB, so Windows no longer prepares 16 MB of call-target bookkeeping at every start.
  `BUN_JSC_jitMemoryReservationSize` still sets another size.
- **Long sessions** ([#189](https://github.com/opensec-git/Pi-Bolt/pull/189),
  [#190](https://github.com/opensec-git/Pi-Bolt/pull/190)): opening or resuming a session of thousands of entries lays each
  message out with less work, and a request no longer tries to read every earlier thinking block's signature as JSON.
- **Idle** ([#191](https://github.com/opensec-git/Pi-Bolt/pull/191)): after an answer, memory is collected once when Pi goes
  quiet, instead of three times.
- **macOS start** ([#188](https://github.com/opensec-git/Pi-Bolt/pull/188)): Pi no longer opens the system log at start
  unless tracing was asked for, which waited on the log service at every start.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
