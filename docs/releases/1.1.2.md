Pi-Bolt 1.1.2 is [1.1.1](1.1.1.md) with `/remote-control`, which lets the Pi-Bolt Android app follow and drive a terminal
session. Pi is still 1.5.0, and the engine and runtimes are 1.1.1's.

### Added

- **`/remote-control`** ([#243](https://github.com/opensec-git/Pi-Bolt/pull/243)): starts a listener and shows a pairing QR
  code for the Pi-Bolt Android app. The phone shows the live session (messages, thinking, tool calls and their output as they
  stream) and can prompt, steer, queue follow-ups, abort, switch model or thinking level, and answer Pi's dialogs.
  `/remote-control tunnel` adds a Cloudflare tunnel (needs `cloudflared`) to connect from anywhere; `copy`, `devices` and
  `stop` copy the pairing link, list and revoke phones, and end it. Every connection is encrypted end to end with Noise
  (`Noise_IK_25519_AESGCM_SHA256`), and only paired phones get past the handshake; a pairing secret is single use and
  expires after 10 minutes. Settings: `remoteControl.port`, `remoteControl.tunnel`, `remoteControl.cloudflared`. See
  [Remote Control](https://github.com/opensec-git/Pi-Bolt/blob/pi-bolt/packages/coding-agent/docs/remote-control.md).
  Nothing of it loads until the command runs, so without it Pi behaves and starts as before.

The Android app ([#243](https://github.com/opensec-git/Pi-Bolt/pull/243),
[#246](https://github.com/opensec-git/Pi-Bolt/pull/246)) is released on its own, under `android-v` tags.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
