Pi-Bolt 1.1.1 is [1.1.0](1.1.0.md) with a fix and a small saving in the editor. Pi is still 1.5.0, and the engine and
runtimes are 1.1.0's.

### Changed

- **Typing in the editor** ([#240](https://github.com/opensec-git/Pi-Bolt/pull/240)): every key press is checked against
  each keybinding. For ordinary typed characters the answer is now remembered, so it is not worked out again on the next
  press. Keys behave as before: the old and new checks agreed on 2.0 M comparisons. Handling typed keys takes about a quarter
  less CPU; a whole interactive session about 1% less.

### Fixed

- **Packages removed by `pi update --extensions`** ([#223](https://github.com/opensec-git/Pi-Bolt/issues/223),
  [#238](https://github.com/opensec-git/Pi-Bolt/pull/238)): an install, update or removal makes npm (or pnpm, bun) prune
  every package in Pi's npm folder that its `package.json` does not list, such as one added with `npm install --no-save`.
  Pi still lets the package manager do that, but now names the packages it removed and says how to keep them: save them as
  dependencies in that `package.json`.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
