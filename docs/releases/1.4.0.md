Pi-Bolt 1.4.0 is [1.3.2](1.3.2.md) with every bug a full review of Pi-Bolt found fixed, fixes for Pi 1.7.0 bugs that are
still open upstream, and a new engine. Pi is 1.7.0, as in 1.3.2. The engine changed, so the runtimes are new.

### Changed

- **grep and find give the results ripgrep and fd give**, and stop walking a folder tree once the limit is reached: a search
  with the default limit in a very large tree takes about a second instead of walking all of it. Within a tree of more than
  10,000 entries, results are in path order within each part of 10,000. find treats an all-lowercase pattern without case, as
  fd does. grep's `glob` applies to folders as well as files, `^$` finds empty lines in files with CRLF line endings, a file
  named on its own is searched even with NUL bytes, UTF-16 files with a byte-order mark are read, ripgrep-style classes such as
  `[[:space:]]` and `\<word\>` are understood, and forms JavaScript has no equivalent for are searched with ripgrep. Ignore files
  follow ripgrep and fd: the global gitignore in nested repositories and outside a repository, `.ignore` files in parent
  folders, and `.ignore` over `.gitignore`.
- **Tools that change files run in order within a message**: bash, write and edit wait for the calls before them, and later
  calls wait for them; other calls still run at the same time. A `read` in the same message as a `bash` that creates the file
  sees it.
- **`pi -p "prompt"` with a stdin pipe** reads stdin only if it sends something within `PI_STDIN_TIMEOUT_MS` (2 s by
  default; `0` waits for the end of input), and says on stderr when it did not read it.
- **Reasoning a provider removed is not sent again** ([#346](https://github.com/opensec-git/Pi-Bolt/issues/346)): after the
  system prompt or the tools change, OpenAI, Azure, Copilot, Codex and Anthropic remove earlier reasoning and say so; Pi-Bolt
  leaves those items out of later requests, also after a resume, and the notice names each removal once.
- **A rollback stays**: after `pi-bolt update --rollback`, automatic updates skip the release rolled back from and install
  only a newer one; `pi-bolt update` installs the latest and clears that.
- **The bash tool's full-output files** are kept in a folder of their own per process (readable by you only) in the temporary
  folder, and each is capped at 256 MiB.
- **Long-running tools no longer stop the process when an update listener fails**, and an unhandled rejection anywhere now
  reports a crash, keeps a crash record and stops tool processes in every mode, as an uncaught exception does.

### Fixed

- **Sessions**: forking a version 1 session file; a session file whose last line is not an entry, or whose entries form a
  cycle; an append that fails partway on a full disk; a dangling `.jsonl` link stopping `--continue`; a repeated entry id in the
  tree; and the HTML export of such files.
- **Compaction** does not retry a failed automatic compaction before every turn, and the request is never limited to one token
  of output.
- **ACP, MCP and RPC**: a cancel sent right after a prompt, or while a prompt waits, cancels it; a dialog the client stops
  waiting for no longer holds the session; two loads of one session open it once; an RPC line that is not a JSON object gets an
  error; abort and Esc work while a prompt is still being checked; settings errors are reported on start and after a reload.
- **Interactive**: autocomplete keeps working after an extension's suggestions fail; deleting one of two markers of the same
  paste keeps the paste; a paste that never ends stops after a second without input, and Ctrl+C always arrives; a Kitty image
  under an overlay comes back when the overlay closes; a row cut to the terminal width no longer colours the next row; the
  fullscreen spinner moves while you scroll; a dialog over an extension's overlay no longer draws the whole transcript.
- **`--tools`** restrictions stay when an extension registers a tool later. An image whose type does not match its bytes is
  read by its bytes.
- **`pi -p`** exits after the run when an MCP server's child keeps its output open.
- **Providers**: Gemini thought signatures are kept when replayed (also through OpenAI-compatible endpoints); an Anthropic
  response that only sends pings times out; more temporary errors are retried and more context-overflow errors recognised, and a
  rate limit no longer starts a compaction; Codex keeps its continuation when the output limit changes and when tool arguments
  were streamed with other spacing, and resends once without compression when the service rejects a compressed request;
  Bedrock retries "Too many tokens"; Copilot shows models the account gains.
- **Engine**: `fetch()` with a slice of a Blob made of Blobs sends the slice; many workers under an address-space limit no
  longer stop the process; `import * as ns` of a built-in module in a module loaded later is a module namespace.
- **Installer and updates**: `pi-bolt doctor` recognises the Linux x86-64 command and installations outside `~/.pi-bolt`, which
  now update automatically; uninstalling stops the remote control service; an interrupted install leaves nothing behind; a full
  disk is reported as one; a stalled download times out; `PIBOLT_BIN_DIR` with a trailing slash or a relative path; two first
  runs of the npm launcher at once.
- **The service**: its control socket is placed in a folder of your own when the agent directory's path is long.
- **Windows**: commands longer than about 8,000 characters run whole in Git Bash.
- **More**: HTML export keeps the `$` of costs; WSL is recognised without its environment variables; the `/tree` summary keeps
  the prompt you go back to; codemode keeps a bounded list of nested calls; `/reload` reports settings errors; cache warming
  after `/reload` uses the reloaded extension; a large edited file is not kept in memory after the edit.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
