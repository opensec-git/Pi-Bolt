Pi-Bolt 1.0.9 is a fix release: after `/new`, the screens of the old session no longer stay in memory, and the engine takes
the root certificates and blocked keys of Bun 1.4.4. Everything else is [1.0.8](1.0.8.md).

### Fixed

- **Memory after `/new`** ([#220](https://github.com/opensec-git/Pi-Bolt/pull/220) by
  [@Shrub24](https://github.com/Shrub24)): a component drawn inside several parents kept every parent it was ever drawn in,
  with their children and rendered lines, for as long as it lived. Across several `/new` in a long session that held old
  message trees (800 MB in one session). Parents are now held weakly and freed once Pi drops them; live parents still
  redraw when the component changes.

### Changed

- **TLS** ([#222](https://github.com/opensec-git/Pi-Bolt/pull/222)): the bundled root certificates are those of NSS 3.131.1
  (118, against 121), and a certificate chain that holds a public key on Node's blocked list fails with `CERT_REVOKED`, as
  in Bun 1.4.4 and Node 22.23.4, 24.22.1 and 26.12.1. This applies to `fetch` (HTTP/3 included), `node:tls`, `node:https`
  and WebSocket.
- **minimatch 11.0.1** ([#221](https://github.com/opensec-git/Pi-Bolt/pull/221)): package resource filters and model
  patterns match as before (5,724 patterns and paths compared with 10.2.6).

Pi is 1.4.0. The runtimes are new: Bun's patch adds #222.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
