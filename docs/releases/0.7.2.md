Pi-Bolt 0.7.2 runs Pi 1.1.0.

### Pi 1.1.0

Everything in Pi [1.1.0](https://github.com/earendil-works/pi/releases/tag/v1.1.0), among it:

- **Claude Haiku 5.5** (`anthropic/claude-haiku-5-5`), with adaptive thinking up to `xhigh`/`max` effort.
- **`--tools` adjusts the defaults** with `+name` and `-name` entries: `pi-bolt -t +codemode,-write`.
- **Program status (OSC 7501):** terminals and agent dashboards that support it see whether Pi-Bolt is working, waiting on a dialog or a login, done, or failed. `PI_PROGRAM_STATUS=1|0` overrides detection.
- Classifier models: OpenAI's GPT-6 Luna through the Decisions API, images in codemode's `models.classify()`, and native llama.cpp decision models through `/v1/systemone`.
- Tool results record how long they ran (`durationMs`), and `Took` stays right after reloading a session.
- `/mcp` opens at once and updates while servers connect; an MCP sign-in can be cancelled with Esc at every step.
- Fixes for codemode output items running together, `server_busy` and Mistral `finish_reason: "error"` responses not being retried, long-prompt pricing tiers undercounting costs, Anthropic browser login when its port is taken, clipboard paste in Termux, and Markdown links in Herdr.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

or `pi-bolt update`, or `npm install -g pi-bolt`. The installer detects Linux or macOS by itself.

| Asset | For |
|---|---|
| `pi-bolt-linux-x64.tar.xz` / `.tar.gz` | **Recommended on Linux.** CPUs with AVX2 (Intel Haswell 2013+, AMD Zen+). |
| `pi-bolt-linux-x64-baseline.tar.xz` / `.tar.gz` | Any x86-64 CPU with SSE4.2. |
| `pi-bolt-linux-x64-jit.tar.xz` / `.tar.gz` | JIT also on, for plugins loaded at run time. |
| `pi-bolt-darwin-arm64.tar.xz` / `.tar.gz` | **macOS.** Macs with Apple silicon, macOS 13 or later. |
| `pi-bolt-darwin-arm64-jit.tar.xz` / `.tar.gz` | macOS, JIT also on. |
| `pi-bolt-runtime-linux-x64.tar.gz`, `pi-bolt-runtime-darwin-arm64.tar.gz` | The Pi-Bolt Bun runtime, for compiling plugins in. |

Linux x86-64 with glibc 2.17 or later; macOS 13 or later on Apple silicon.
