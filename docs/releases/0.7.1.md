Pi-Bolt 0.7.1 runs Pi 1.0.4, and Pi and Pi-Bolt can now load different packages from the same agent directory.

### Pi and Pi-Bolt side by side

- **A package list of Pi-Bolt's own.** Pi-Bolt shares Pi's agent directory (`~/.pi/agent`), so a package installed for one was loaded by the other, and two packages that provide the same tool, such as `@juicesharp/rpiv-todo` in Pi and `opensec-pi-todo` in Pi-Bolt, could not load together. A `piBolt.packages` list in `settings.json` is now read and changed by Pi-Bolt in place of `packages`, which Pi keeps using ([README](../../README.md#pi-and-pi-bolt-side-by-side)). Removing a package from Pi-Bolt's list keeps the files of one that Pi's list still uses.
- A tool that two packages provide says how to resolve it.

### Pi 1.0.4

Everything in Pi [1.0.4](https://github.com/earendil-works/pi/releases/tag/v1.0.4), among it:

- `--tools` and `--exclude-tools` take `*` patterns (`--tools read,codemode,'mcp__radius__*'`), `--tools` keeps MCP tools, and `--no-mcp` turns MCP off for one run.
- Codemode's `tools.read()` gives an image block for an image file.
- Fixes for syntax colors after the first line of multiline strings and comments, MCP sign-in with OpenID Connect client registration, MCP shutdown while a server is connecting, retried Bedrock requests after a stalled HTTP/2 connection, and codemode scripts that patch built-ins.

### Fixes

- Provider compatibility is detected from the base URL's host name, not from a substring anywhere in the URL.
- Packages from git are passed to `git` after `--end-of-options`, and a repository or ref that starts with `-` is refused.
- Skill blocks, diff lines, prompt-template arguments and LaTeX script values are parsed in one pass.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

or `pi-bolt update`, or `npm install -g pi-bolt`. The installer detects Linux or macOS by itself.

| Asset | For |
|---|---|
| `pi-bolt-linux-x64.tar.xz` / `.tar.gz` | **Recommended on Linux.** CPUs with AVX2 (Intel Haswell 2013+, AMD Zen+). |
| `pi-bolt-linux-x64-baseline.tar.xz` / `.tar.gz` | Any x86-64 CPU with SSE4.2. |
| `pi-bolt-linux-x64-jit.tar.xz` / `.tar.gz` | JIT also on, for plugins loaded at run time. |
| `pi-bolt-darwin-arm64.tar.xz` / `.tar.gz` | **macOS.** Macs with Apple silicon, macOS 13 or later. |
| `pi-bolt-darwin-arm64-jit.tar.xz` / `.tar.gz` | macOS, JIT also on. |
| `pi-bolt-runtime-linux-x64.tar.gz`, `pi-bolt-runtime-darwin-arm64.tar.gz` | The Pi-Bolt Bun runtime, for compiling plugins in. |

Linux x86-64 with glibc 2.17 or later; macOS 13 or later on Apple silicon.
