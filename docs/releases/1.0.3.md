Pi-Bolt 1.0.3 is a performance release: Pi starts sooner, answers a one-shot prompt with less work, draws a streamed answer
and a long session with less CPU, wakes less while idle and keeps less memory, on new runtimes. It also fixes `pi-bolt update`
when GitHub's API limit is reached and extensions that `await` at their top level. Everything else is [1.0.2](1.0.2.md).

### Changed

- **Long sessions:** a regular-mode frame no longer copies the whole transcript. An answer into a 4,000-entry session costs
  0.41 s CPU instead of 0.88 s on Linux x86-64 ([#134](https://github.com/opensec-git/Pi-Bolt/pull/134)).
- **Streaming:** a streamed chunk costs less to draw, and the spinner's steps ride on the frames the answer draws anyway, so a
  long answer draws about 19% fewer frames. A 60,000-character answer runs about 25% fewer instructions than in 1.0.2
  ([#140](https://github.com/opensec-git/Pi-Bolt/pull/140), [#147](https://github.com/opensec-git/Pi-Bolt/pull/147)).
- **Startup:** less work before the first frame and the first request; `pi --version` and `pi -p` create only the functions
  they load ([#136](https://github.com/opensec-git/Pi-Bolt/pull/136), [#143](https://github.com/opensec-git/Pi-Bolt/pull/143)).
  On macOS, Pi-Bolt binds libSystem's imports through a copy of the library beside the executable
  ([#139](https://github.com/opensec-git/Pi-Bolt/pull/139)).
- **The first emoji or symbol on screen** no longer builds Unicode's full emoji matcher
  ([#144](https://github.com/opensec-git/Pi-Bolt/pull/144)).
- **Compiled code:** `includes`, `indexOf`, `slice`, `at` and `concat` on a value that may be a string or an array take the
  string or array path directly ([#154](https://github.com/opensec-git/Pi-Bolt/pull/154)).
- **Memory and idle:**
  - On Linux, Pi's first collection comes after 16 MB, not 24.6 MB ([#138](https://github.com/opensec-git/Pi-Bolt/pull/138)).
  - `pi -p` and other batch runs start with a 48 MB collection allowance, so a one-shot prompt usually needs no collection
    ([#146](https://github.com/opensec-git/Pi-Bolt/pull/146)).
  - The allocator's scavenger sleeps while there is nothing to give back
    ([#137](https://github.com/opensec-git/Pi-Bolt/pull/137)), and builds without the JIT drop the idle collection two
    minutes after the last activity ([#148](https://github.com/opensec-git/Pi-Bolt/pull/148)).
- **`find` and `grep`** take back the 3% that 1.0.2's linear globs cost ([#132](https://github.com/opensec-git/Pi-Bolt/pull/132)).

### Fixed

- **`pi-bolt update` when GitHub's API limit is reached:** the latest version is read from the `releases/latest` redirect, as
  the installers do, and a failed lookup says why. The startup update notice no longer uses the API either
  ([#149](https://github.com/opensec-git/Pi-Bolt/issues/149), [#150](https://github.com/opensec-git/Pi-Bolt/pull/150)).
  1.0.2 still asks the API: if `pi-bolt update` on 1.0.2 says it could not determine the latest version, wait for the hourly
  limit to reset or run the installer again (below).
- **Extensions that `await` at their top level compile again**, and each extension is compiled on its own again, so several
  small extensions no longer add up to the compiler's limit
  ([#142](https://github.com/opensec-git/Pi-Bolt/issues/142), [#129](https://github.com/opensec-git/Pi-Bolt/issues/129),
  [#152](https://github.com/opensec-git/Pi-Bolt/pull/152)).
- **The garbage collector** records a completely full block it gives up as allocated
  ([#145](https://github.com/opensec-git/Pi-Bolt/pull/145)).
- **The compiler and the JIT:** fixes from upstream WebKit for B3/Air (two miscompiles, and the upper 32 bits of a value on
  x86-64), the JIT's tier-up while a compile is in flight, catch OSR entry and FTL tail calls. Compiled code reaches B3/Air
  in every build; in the `-jit` builds, a plugin whose code tiers up runs a session with about 8% fewer instructions
  ([#153](https://github.com/opensec-git/Pi-Bolt/pull/153)).

With the default settings Pi draws the same screens and sends the same requests as 1.0.2.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, an installed Pi-Bolt, or `ssh-keygen` (OpenSSH 8.1 or later).
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
