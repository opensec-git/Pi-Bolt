# Pi-Bolt 1.0.8

Pi-Bolt 1.0.8 adds automatic, signed updates for native-installer installations. Pi-Bolt checks the selected release channel at startup and installs a newer release in the background; restart Pi-Bolt to use it. Set `PIBOLT_AUTO_UPDATE=0` to turn this off. npm, Homebrew, Scoop and mise installations remain managed by their package managers.

### Added

- **Automatic updates for native installs:** the startup version check now runs the existing verified self-update flow for native installer-managed builds, without requiring Node.js or Bun. Update failures include a manual retry command.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```
