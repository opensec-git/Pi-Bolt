# Pi-Bolt 1.0.8

Pi-Bolt 1.0.8 adds automatic signed updates for native-installer installations. See the [README](../../README.md#quick-start) for update behavior and setup details.

### Added

- **Automatic updates for native installs:** the startup version check can apply the existing verified self-update flow without requiring Node.js or Bun.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```
