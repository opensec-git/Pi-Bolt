Pi-Bolt 1.1.3 is [1.1.2](1.1.2.md) with `/remote-control` reaching the phone from anywhere by default. Pi is still 1.5.0,
and the engine and runtimes are 1.1.1's.

### Changed

- **`/remote-control` starts the Cloudflare tunnel by default** ([#251](https://github.com/opensec-git/Pi-Bolt/pull/251)):
  when `cloudflared` is installed, plain `/remote-control` starts the tunnel (a quick tunnel, or the named one in
  `remoteControl.tunnel`) together with the LAN listener, so the phone connects on the same network or from anywhere. If the
  tunnel fails, the LAN keeps working and a warning is shown; `/remote-control tunnel` still treats a tunnel failure as an
  error. The first time `cloudflared` is missing, Pi offers to install it (`brew` on macOS, `winget` on Windows, run only
  if you choose it; on Linux it shows the download page), to stay on the LAN for now, or not to ask again
  (`remoteControl.askCloudflared: false`). `/remote-control lan` is local only and stops a running tunnel;
  `remoteControl.tunnel: "off"` makes that the default. Tailscale addresses in the pairing code are labelled `tailscale`.
  Nothing of it loads until the command runs.

Also since 1.1.2, outside the release archives:

  ([#245](https://github.com/opensec-git/Pi-Bolt/pull/245)).

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`, or:

- Homebrew (macOS on Apple silicon, Linux): `brew install opensec-git/tap/pi-bolt`
- Scoop (Windows): `scoop bucket add opensec-git https://github.com/opensec-git/scoop-bucket`, then `scoop install opensec-git/pi-bolt`
- mise: `github:opensec-git/Pi-Bolt` with the options in the [installation guide](https://pi-bolt.opensec.in/docs/installation.html)

The installer checks the release signature with OpenSSL 3, `ssh-keygen` (OpenSSH 8.1 or later), or an installed Pi-Bolt.
Every archive also has a GitHub build attestation: `gh attestation verify <file> -R opensec-git/Pi-Bolt`.
