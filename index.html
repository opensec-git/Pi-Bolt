// 01 ExtensionsDo my extensions work?+

Yes, unchanged. Pi's own code is compiled to machine code; an extension loaded at run time is interpreted, which light extensions don't notice. For heavy ones, pi-bolt compile compiles them into your build, or install the JIT build.

// 02 PiDoes it replace Pi?+

No. It installs next to Pi as pi-bolt and uses your configuration in ~/.pi/agent as it is, so both can stay installed and you can switch back anytime.

// 03 PlatformsWhere does it run?+

Linux x86-64 and ARM64 with glibc 2.17 or later, macOS 13 or later on Apple silicon, Windows 10 (1809) or 11 on x64, and Android 7 or later in Termux. Windows on ARM runs the x64 build.

// 04 UpdatesHow do I update, or go back?+

pi-bolt update installs the latest release, and pi-bolt update --rollback puts back the build it replaced. Every release is signed, and the installer and the updater check the signature before installing anything.
